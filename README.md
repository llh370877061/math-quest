# 数学闯关站 Math Quest

一个免费、开源的闯关式数学学习网站，覆盖 1–9 年级（小学加初中）。

**在线使用：** 部署到 GitHub Pages 后，打开 `https://<你的用户名>.github.io/math-quest/` 即可，无需安装、无需注册。
也可以下载 `index.html`，双击用浏览器打开（推荐 Edge，语音讲解更自然）。

## 功能
- 选教材：小学/初中 → 年级 → 上下册 → 版本（人教、北师大、苏教、华师大），共 55 本
- 今日训练：选择、填空、连线、应用题，题目由程序自动生成
- AI 小课堂、讲解视频、知识地图（88 个知识点）
- 电子书（可划重点、写笔记、加书签）
- 试卷中心：单元、月考、期中、期末、小升初、精选、竞赛
- 错题本与周报告、1 分钟口算、打卡、护眼操、宠物、积分商城、排行榜（成绩码）

## 说明
- 单个 HTML 文件，无服务器；学习进度保存在使用者自己的浏览器里，不上传任何数据。
- 电子书为本项目原创的“同步知识手册”，精选卷与竞赛卷题目为原创，均不含出版社课本原文。
- 各教材版本的单元目录按常见版本整理，可能与实际课本略有出入，可用“自定义单元”。
- 语音讲解使用浏览器自带的语音合成。
- 本项目大部分代码由 AI 助手 Claude 按作者提出的需求编写，并经作者测试。
